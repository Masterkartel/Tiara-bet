# Crash Game (KES + M-Pesa Till)

Real-time multiplayer crash game with M-Pesa Till deposits and pending KES withdrawals.

## Features
- Real-time crash game (Socket.IO)
- KES balance per player
- M-Pesa STK Push deposits (Buy Goods / Till)
- Pending withdrawals with admin approval
- Simple admin panel

## Tech Stack
- Node.js + Express
- Socket.IO
- MongoDB (Mongoose)
- Safaricom Daraja (STK Push)
